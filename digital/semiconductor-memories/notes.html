Chapter 01 · Part 1

Semiconductor Memory Taxonomy & Capacity Mathematics

Semiconductor memories form the backbone of modern digital computing and microelectronic systems. In GATE ECE/EE/CS, questions rigorously evaluate memory hierarchy, internal cell topologies, timing constraints, array addressing, and programmable logic.

Memory Taxonomy & Fundamental Classifications

Memory devices are fundamentally categorized along two axes: retention mechanism (volatile vs non-volatile) and access mode (random access vs sequential access).

Parameter Static RAM (SRAM) Dynamic RAM (DRAM) Read-Only Memory (ROM)
Storage Cell Cross-coupled CMOS latch (4T or 6T) Storage capacitor + 1 pass transistor (1T-1C) Fixed diode/transistor crosspoint array
Volatility Volatile (loses data on power loss) Volatile (loses data on power loss) Non-Volatile (retains data permanently)
Refresh Requirement None (static bistable state) Periodic refresh mandatory ($2 - 64\text{ ms}$) None
Read Mechanism Non-destructive differential sense Destructive (requires automatic rewrite) Non-destructive sense
Speed / Access Time Ultra-fast ($0.5 - 5\text{ ns}$) Moderate ($10 - 50\text{ ns}$) Moderate to slow ($10 - 100\text{ ns}$)
Packing Density & Cost Low density (large cell area), High cost Ultra-high density, Low cost per bit Very high density, Low cost
Primary Application CPU L1/L2/L3 Cache, Register files Main System Memory (DDR4/DDR5) Boot firmware (BIOS/UEFI), lookup tables
📌 Memory Capacity Mathematical Formulation

For a memory organized as $M \times N$ (where $M$ is the number of words, and $N$ is the word size in bits):

$$k = \log_2(M) \quad \Longleftrightarrow \quad M = 2^k \text{ addressable locations}$$ $$\text{Total Capacity (Bits)} = M \times N = 2^k \times N$$ $$\text{Total Capacity (Bytes)} = \frac{2^k \times N}{8}$$

Here, $k$ input address lines are required to uniquely decode all $M$ word lines via a $k$-to-$2^k$ binary decoder.

Chapter 01 · Part 2

Static RAM (SRAM): The 6T CMOS Cell & Operational States

A Static Random Access Memory (SRAM) stores each bit of information in a bistable latching circuit. Unlike dynamic RAM, it does not require periodic refreshing because the cross-coupled inverters continuously regenerate the stored charge via positive feedback.

The 6T CMOS SRAM Cell Architecture

The standard full-CMOS SRAM cell comprises 6 MOS transistors: two PMOS pull-up transistors ($P_1, P_2$), two NMOS pull-down transistors ($N_1, N_2$), and two NMOS access (pass-gate) transistors ($A_1, A_2$).

🔬 Transistor Breakdown of the 6T SRAM Cell
  • Inverter 1: Composed of $P_1$ and $N_1$, producing internal storage node $Q$.
  • Inverter 2: Composed of $P_2$ and $N_2$, producing complementary storage node $\overline{Q}$.
  • Access Transistors ($A_1, A_2$): Connected between storage nodes and the differential bit lines ($BL, \overline{BL}$), with gates driven by the Word Line ($WL$).

Operational Cycles of the 6T SRAM Cell

  1. Standby / Retention ($WL = 0$): Access transistors $A_1, A_2$ are OFF. The cross-coupled inverters maintain stable states $Q$ and $\overline{Q}$ powered by $V_{DD}$. Static power dissipation is limited purely to subthreshold leakage.
  2. Read Cycle:
    • Both Bit Lines ($BL$ and $\overline{BL}$) are precharged to $V_{DD}$.
    • The Word Line ($WL$) is driven HIGH ($1$). Both access transistors $A_1, A_2$ turn ON.
    • If $Q = 0$ and $\overline{Q} = 1$, node $Q$ discharges $BL$ through $N_1$ and $A_1$. Meanwhile, $\overline{BL}$ remains at $V_{DD}$.
    • A sensitive analog Sense Amplifier detects the small differential voltage $\Delta V = V_{BL} - V_{\overline{BL}}$ (typically $50 - 100\text{ mV}$) and converts it to a full CMOS digital level.
    • Non-destructive: The internal node values are never flipped during read if correctly sized ($eta_{N1} > eta_{A1}$, the cell ratio constraint).
  3. Write Cycle:
    • The write drivers drive the bit lines to the desired data: $BL = D$, $\overline{BL} = \overline{D}$.
    • $WL$ is asserted HIGH. The strong write driver forces the internal node to flip, overpowering the PMOS pull-up transistor (pull-up ratio constraint: $eta_{A1} > eta_{P1}$).
    • $WL$ returns LOW, locking the new state into the bistable latch.
⚠️ Common GATE Examiner Trap: SRAM Transistor Count

Exam questions frequently test: "Each cell of a static RAM contains how many MOS transistors?"

The answer is 6 MOS transistors (4 NMOS + 2 PMOS). Older NMOS-only SRAMs used 4 NMOS with polysilicon pull-up resistors (4T cell), but modern and standard GATE syllabus questions define the full MOS SRAM cell as 6 MOS transistors (GATE 1996, Q3).

Chapter 01 · Part 3

Dynamic RAM (DRAM): 1T-1C Cell, Destructive Read & Refreshing

Dynamic Random Access Memory (DRAM) achieves unmatched storage density by storing each bit of information as electric charge on an integrated capacitor ($C_s$).

The 1T-1C DRAM Cell

A single dynamic RAM cell requires only 1 MOS transistor and 1 storage capacitor (1T-1C topology):

  • Transistor ($M_1$): An NMOS pass transistor acting as a bidirectional transmission switch. Its gate is connected to the Word Line ($WL$), and its drain is connected to the Bit Line ($BL$).
  • Capacitor ($C_s$): A microscopic trench or stacked capacitor ($20 - 50\text{ fF}$) connected between the source of $M_1$ and a reference plate voltage ($V_{DD}/2$).
⚡ Physics of Destructive Read & Charge Sharing

When $WL$ goes HIGH, the charge on $C_s$ is dumped onto the precharged bit line with capacitance $C_{BL}$ ($C_{BL} \gg C_s$, typically $10\times$ to $20\times$ larger). The resulting voltage perturbation on $BL$ is governed by charge conservation:

$$\Delta V_{BL} = \frac{C_s}{C_{BL} + C_s} \left(V_s - \frac{V_{DD}}{2}\right)$$

Because the charge on $C_s$ is perturbed, the read operation is destructive. The sense amplifier must immediately restore (rewrite) full voltage back to $C_s$ before $WL$ closes!

Why Refreshing is Mandatory

Charge stored on the capacitor inevitably leaks away over time due to:

  1. Subthreshold leakage through the access transistor $M_1$.
  2. Reverse-bias p-n junction leakage between the diffusion node and substrate.
  3. Dielectric leakage through the capacitor insulator.

To prevent catastrophic data loss, every row of the DRAM array must be read, amplified, and restored within the retention time ($t_{ref} \approx 2\text{ ms}$ to $64\text{ ms}$). This periodic restoration is called DRAM Refreshing.

⚠️ Examiner Trap: Simultaneous Read and Write

Can read and write operations be performed simultaneously in a standard single-port DRAM cell?

ABSOLUTELY NOT. Both read and write operations share the exact same physical bit line and sense amplifier. During read, the bit line is sensed and restored; a write operation requires driving the bit line externally. Simultaneous read and write on the same cell/bus is physically impossible (GATE 2017, Q1).

Chapter 01 · Part 4

ROM Arrays & Programmable Logic Devices (PROM, PAL, PLA)

Read-Only Memories (ROM) and Programmable Logic Devices (PLDs) are combinational/sequential logic structures built from arrays of AND gates and OR gates.

Diode ROM Matrix Operation

A diode ROM consists of orthogonal grid lines: horizontal Word Lines ($W_i$) and vertical Bit Lines ($B_j$) with pull-down resistors to ground:

  • When word line $W_i$ is asserted HIGH, any intersection containing a forward-connected diode pulls bit line $B_j$ HIGH ($ ext{Logic } 1$).
  • If no diode is present at the intersection $(i, j)$, bit line $B_j$ remains pulled down to $0\text{ V}$ by its resistor ($ ext{Logic } 0$).
  • Therefore: $\text{Diode Present} \implies D_{ij} = 1$; $\text{No Diode} \implies D_{ij} = 0$.

Architectural Comparison of PLDs (PROM vs PAL vs PLA)

The three classical Programmable Logic Devices are characterized entirely by whether their constituent AND and OR arrays are fixed or programmable:

Device AND Array OR Array Minterm Generation Flexibility & Speed
PROM (Programmable ROM) Fixed (Full binary decoder) Programmable Generates all $2^n$ canonical minterms Moderate speed; inefficient if only few minterms needed
PAL (Programmable Array Logic) Programmable Fixed Generates only required product terms Fastest (fixed OR gates have minimal capacitive load)
PLA (Programmable Logic Array) Programmable Programmable Generates custom product terms, shared across OR gates Highest logic density & flexibility; slightly slower
💡 GATE AIR 1 Mnemonic: "PROMs Fix the AND, PALs Fix the OR, PLAs Fix Nothing"

Remember this simple rule: $$\text{PROM: Fixed AND } + \text{ Prog OR}$$ $$\text{PAL: Prog AND } + \text{ Fixed OR}$$ $$\text{PLA: Prog AND } + \text{ Prog OR}$$ This exact distinction is tested repeatedly in GATE (GATE 1992 Q7, GATE 1994 Q5).

Chapter 01 · Part 5

2D Coincident Decoding, Aspect Ratios & Array Expansion

Practical memory chips are organized as two-dimensional (2D) or 2.5D square arrays rather than long linear strips to minimize word line RC delay and decoder gate counts.

2D Memory Organization (Row & Column Decoding)

For a memory storing $B$ total bits arranged as a square array with an aspect ratio of 1 (Number of Rows = Number of Columns):

$$N_{rows} = N_{cols} = \sqrt{B}$$ $$\text{Row Address Lines } (k_r) = \log_2(N_{rows}) = \log_2(\sqrt{B}) = \frac{1}{2} \log_2(B)$$ $$\text{Column Address Lines } (k_c) = \log_2(N_{cols}) = \frac{1}{2} \log_2(B)$$
📐 Example: 16 Kb Square Array (GATE 2015 Set 1, Q2)

Given: Total bits $B = 16\text{ Kb} = 16 \times 1024 = 16,384\text{ bits}$.

$$N_{rows} = \sqrt{16,384} = 128\text{ rows}$$ $$k_r = \log_2(128) = 7\text{ address lines for the row decoder}$$

Single Decoder vs 2D Decoding Gate Counts

When addressing a memory of $M = 2^k$ words using a single linear decoder:

  • The decoder has $k$ inputs and $M = 2^k$ output word lines.
  • Each output word line corresponds to one distinct minterm of the $k$ address bits.
  • Therefore, the decoder requires exactly $2^k$ AND gates (each with $k$ inputs).
⚠️ Examiner Trap: Word Count vs Data Width in Decoder Sizing (GATE 2021, Q8)

Consider a $32\text{K} \times 16$ memory chip:

  • $32\text{K} = 32 \times 1024 = 2^5 \times 2^{10} = 2^{15}$ words.
  • The word size is 16 bits (each word has 16 data bits).
  • Question: How many AND gates are required for a single address decoder?
  • Trap: Many students erroneously use 16 (the data width) or combine address + data!
  • Correct: The address decoder only selects the words (rows)! With $2^{15}$ words, the single decoder requires $k = 15$ address lines and exactly $2^{15} = 32,768$ AND gates!

Q1. GATE ECE 2017 Set 2 1 Mark MCQ

In a DRAM,

(A) periodic refreshing is not required
(B) information is stored in a capacitor
(C) information is stored in a latch
(D) both read and write operations can be performed simultaneously
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Recall the physical architecture of a Dynamic Random Access Memory (DRAM) cell.
  2. A standard DRAM cell consists of a single access NMOS transistor and a storage capacitor (1T-1C structure).
  3. Data (logic 1 or logic 0) is stored as electrostatic charge $Q = C_s V$ on this microscopic capacitor ($C_s \approx 20 - 50\text{ fF}$).
  4. Because charge leaks over time through p-n junctions and subthreshold paths, periodic refreshing IS strictly required (invalidating Option A).
  5. Information stored in a cross-coupled latch characterizes an SRAM cell, not DRAM (invalidating Option C).
  6. Read and write share the same bitline and cannot be done simultaneously (invalidating Option D).
  7. Thus, statement (B) is the sole correct physical fact.
Official ExamGOAL Answer Key: (B)
⚠️ Examiner Trap Alert

Do not confuse SRAM (stores in cross-coupled latch) with DRAM (stores charge on capacitor).

Q2. GATE ECE 2015 Set 1 1 Mark NAT

A $16\text{ Kb}$ ($= 16,384\text{ bit}$) memory array is designed as a square with an aspect ratio of one (number of rows is equal to the number of columns). The minimum number of address lines needed for the row decoder is _______.

🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Total storage capacity in bits $B = 16\text{ Kb} = 16,384\text{ bits}$.
  2. Given aspect ratio $R = 1 \implies \text{Number of Rows } (N_R) = \text{Number of Columns } (N_C)$.
  3. Since $B = N_R \times N_C = N_R^2$, we calculate the number of rows:
    $$N_R = \sqrt{16,384} = 128\text{ rows}$$
  4. The row decoder must uniquely select one of these 128 rows.
  5. Number of address lines required for the row decoder $k_R = \log_2(128) = \log_2(2^7) = 7\text{ lines}$.
Official ExamGOAL Answer Key: 7
⚠️ Examiner Trap Alert

Be careful with units: '16 Kb' means 16 Kilobits = 16,384 bits. Do not confuse with 16 KBytes (which would be $16 \times 8 \text{ Kb}$).

Q3. GATE ECE 1996 1 Mark MCQ

Each cell of a static Random Access Memory Contains

(A) 6 MOS transistors.
(B) 4 MOS transistors and 2 capacitors
(C) 2 MOS transistors and 4 capacitors
(D) 1 MOS transistors and 1 capacitors
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Static RAM (SRAM) stores data without capacitors.
  2. The standard CMOS static memory cell consists of two cross-coupled CMOS inverters (each inverter has 1 PMOS and 1 NMOS = 4 transistors) plus two NMOS access/pass transistors controlled by the Word Line ($WL$).
  3. Total MOS transistors $= 2\text{ PMOS} + 4\text{ NMOS} = 6\text{ MOS transistors}$.
Official ExamGOAL Answer Key: (A)
⚠️ Examiner Trap Alert

Option D describes a DRAM cell (1 MOS transistor and 1 capacitor). SRAM cells use zero capacitors.

Q4. GATE ECE 1995 1 Mark MCQ

The minimum number of MOS transistors required to make a dynamic RAM cell is

(A) 1
(B) 2
(C) 3
(D) 4
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. A standard modern dynamic RAM (DRAM) cell uses the 1T-1C architecture.
  2. This consists of exactly 1 MOS access transistor and 1 storage capacitor.
  3. Thus, the minimum number of MOS transistors required is 1.
Official ExamGOAL Answer Key: (A)
⚠️ Examiner Trap Alert

Early DRAMs historically used 3-transistor cells (3T DRAM), but the modern minimum tested in GATE is 1 transistor.

Q5. GATE ECE 1994 1 Mark MCQ

A PLA can be used

(A) as a microprocessor
(B) as a dynamic memory
(C) to realize a sequential logic
(D) to realize a combinational logic
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. A PLA (Programmable Logic Array) consists of a programmable AND array followed by a programmable OR array.
  2. This two-level structure directly implements arbitrary Boolean sum-of-products (SOP) expressions.
  3. Hence, it is fundamentally used to realize combinational logic circuits.
Official ExamGOAL Answer Key: (D)
⚠️ Examiner Trap Alert

While sequential PLAs exist (Registered PLAs with flip-flops), a standard fundamental PLA is a combinational logic device.

Q6. GATE ECE 1994 1 Mark MCQ

A dynamic RAM consists of

(A) 6 transistors
(B) 2 transistors and 2 capacitor
(C) 1 transistors and 1 capacitor
(D) 2 capacitor only
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. A dynamic RAM bit cell stores data in the 1T-1C configuration.
  2. It consists of 1 access NMOS transistor and 1 storage capacitor.
Official ExamGOAL Answer Key: (C)
⚠️ Examiner Trap Alert

Compare directly with Q3: SRAM = 6 transistors; DRAM = 1 transistor + 1 capacitor.

Q7. GATE ECE 1992 1 Mark MSQ / Multi-Answer

Choose the correct statement(s) from the following:

(A) PROM contains a programmable AND array and a fixed OR array.
(B) PLA contains a fixed AND array and a programmable OR array
(C) PROM contains a fixed AND array and a programmable OR array
(D) PLA contains a programmable AND array and a programmable OR array
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Let us evaluate the structure of each Programmable Logic Device:
  2. 1. PROM: Consists of a full decoder (Fixed AND array generating all $2^n$ minterms) and a Programmable OR array. Hence (C) is TRUE and (A) is FALSE.
  3. 2. PAL: Consists of a Programmable AND array and a Fixed OR array.
  4. 3. PLA: Consists of a Programmable AND array and a Programmable OR array. Hence (D) is TRUE and (B) is FALSE.
  5. Therefore, both (C) and (D) are correct statements.
Official ExamGOAL Answer Key: (C) and (D)
⚠️ Examiner Trap Alert

Remember: PLA has BOTH arrays programmable. PROM has fixed AND (decoder) + programmable OR.

Q8. GATE ECE 2021 2 Marks MCQ

Addressing of a $32\text{K} \times 16$ memory is realized using a single decoder. The minimum number of AND gates required for the decoder is :

(A) $2^4$
(B) $2^8$
(C) $2^{16}$
(D) $2^{15}$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Analyze the memory specifications: $32\text{K} \times 16$.
  2. This memory has $32\text{K}$ addressable words, where each word is 16 bits wide.
  3. Calculate the number of address lines $k$ required to uniquely select each word:
    $$M = 32\text{K} = 32 \times 1024 = 2^5 \times 2^{10} = 2^{15} \text{ words} \implies k = 15 \text{ address lines}$$
  4. A single decoder decoding $k$ input address lines must produce $2^k$ distinct output word-select lines.
  5. Each output line corresponds to one unique minterm, which requires one AND gate.
  6. Therefore, the minimum number of AND gates required for the decoder is $2^{15} = 32,768$.
Official ExamGOAL Answer Key: (D) $2^{15}$
⚠️ Examiner Trap Alert

Do NOT get confused by the word length '16'. The decoder decodes the word address ($2^{15}$), NOT the data bits! Hence the answer is $2^{15}$, not $2^{16}$.

Q9. GATE ECE 2018 2 Marks MCQ

A $2 \times 2$ ROM array is built with the help of diodes as shown in the circuit below. Here $W_0$ and $W_1$ are signals that select the word lines and $B_0$ and $B_1$ are signals that are output of the sense amps based on the stored data corresponding to the bit lines during the read operation.

During the read operation, the selected word line goes high and the other word line is in a high impedance state. As per the implementation shown in the circuit diagram above, what are the bits corresponding to $D_{ij}$ (where $i = 0$ or $1$ and $j = 0$ or $1$) stored in the ROM?

(A) $[D_{00}, D_{01}, D_{10}, D_{11}] = [1, 0, 0, 1]$
(B) $[D_{00}, D_{01}, D_{10}, D_{11}] = [0, 1, 1, 0]$
(C) $[D_{00}, D_{01}, D_{10}, D_{11}] = [1, 1, 0, 0]$
(D) $[D_{00}, D_{01}, D_{10}, D_{11}] = [0, 0, 1, 1]$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Inspect the diode matrix schematic at each grid intersection $(i, j)$ where $i$ is the word line index ($W_0, W_1$) and $j$ is the bit line index ($B_0, B_1$):
  2. 1. Row 0 ($W_0$ selected HIGH):
  3. - At intersection $(0, 0)$, a diode connects $W_0$ (anode) to $B_0$ (cathode). When $W_0$ is HIGH, the diode conducts, pulling $B_0$ HIGH $\implies D_{00} = 1$.
  4. - At intersection $(0, 1)$, there is NO diode between $W_0$ and $B_1$. Hence $B_1$ remains at pull-down ground potential $\implies D_{01} = 0$.
  5. 2. Row 1 ($W_1$ selected HIGH):
  6. - At intersection $(1, 0)$, there is NO diode between $W_1$ and $B_0$. $B_0$ remains at ground $\implies D_{10} = 0$.
  7. - At intersection $(1, 1)$, a diode connects $W_1$ (anode) to $B_1$ (cathode). When $W_1$ is HIGH, the diode conducts, pulling $B_1$ HIGH $\implies D_{11} = 1$.
  8. 3. Assembling the stored bits matrix:
    $$D = \begin{bmatrix} D_{00} & D_{01} \\ D_{10} & D_{11} \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$
  9. Hence, the stored bits are $[1, 0, 0, 1]$ corresponding to Option (A).
Official ExamGOAL Answer Key: (A) [1, 0, 0, 1]
⚠️ Examiner Trap Alert

Diode anode is on Word Line, cathode is on Bit Line. When Word Line is HIGH, diode conducts $\implies$ Bit Line is 1. No diode $\implies$ Bit Line pulled down to 0.

Q10. GATE ECE 2014 Set 3 2 Marks MCQ

If $WL$ is the Word Line and $BL$ the Bit Line, an SRAM cell is shown in

(A) Circuit with NMOS load cross-coupled to Bit lines
(B) Circuit with cross-coupled CMOS inverters and NMOS pass gates to $BL$ and $\overline{BL}$ driven by $WL$
(C) Circuit with dynamic capacitor storage
(D) Single inverter feedback loop
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. The standard 6T CMOS SRAM cell consists of two cross-coupled CMOS inverters.
  2. Each inverter is formed by a PMOS pull-up connected to $V_{DD}$ and an NMOS pull-down connected to Ground.
  3. The output of the first inverter drives the input of the second, and vice-versa, creating a bistable storage latch with nodes $Q$ and $\overline{Q}$.
  4. Two NMOS pass (access) transistors have their gates driven by the Word Line ($WL$).
  5. One access transistor connects node $Q$ to the Bit Line ($BL$), and the other connects node $\overline{Q}$ to the complementary Bit Line ($\overline{BL}$).
  6. Circuit (B) exactly depicts this classic symmetric 6T CMOS SRAM cell configuration.
Official ExamGOAL Answer Key: (B)
⚠️ Examiner Trap Alert

Ensure access gates are tied to Word Line ($WL$), NOT Bit Line! Word line controls whether the cell is selected.

Q11. GATE ECE 2003 2 Marks MCQ

In the circuit shown in Figure, A is a parallel-in, parallel-out 4-bit register, which loads at the rising edge of the clock $C$. The input lines are connected to a 4-bit bus, $W$. Its output acts as the input to a $16 \times 4$ ROM whose output is floating when the enable input $E$ is 0. A partial table of the contents of the ROM is as follows:
• Address 0110 (6) $\to$ Data 1000
• Address 1000 (8) $\to$ Data 1011

The clock to the register is shown, and the data on the $W$ bus at time $t_1$ is $0110$. The data on the bus at time $t_2$ is

(A) 1111
(B) 1011
(C) 1000
(D) 0010
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Trace the sequential timing cycle through the register and ROM:
  2. 1. Initial state before $t_1$: Bus $W$ carries data $0110_2$ (decimal 6).
  3. 2. At time $t_1$ (First rising edge of clock $C$):
  4. - Register A loads the data currently present on the $W$ bus.
  5. - Output of Register A becomes $0110_2$.
  6. - This output immediately applies address $0110_2$ to the address inputs of the $16 \times 4$ ROM.
  7. 3. During the high phase between $t_1$ and $t_2$:
  8. - When the ROM enable input $E$ is activated, the ROM accesses location $0110_2$.
  9. - From the provided ROM lookup table, location $0110_2$ contains data: 1000.
  10. - The ROM drives this data (1000) onto the $W$ bus.
  11. 4. At time $t_2$ (Second rising edge of clock $C$):
  12. - Right at the instant of $t_2$, the data present on the $W$ bus is the ROM output from address $0110$, which is 1000.
  13. Hence, the data on the bus at time $t_2$ is 1000 (Option C).
Official ExamGOAL Answer Key: (C) 1000
⚠️ Examiner Trap Alert

Do not look ahead to the next cycle! At time $t_2$, the register is just beginning to sample $1000$; therefore the bus holds 1000, NOT the data at address 1000 (which is 1011).

Q12. GATE ECE 2002 2 Marks MCQ

If the input $X_3, X_2, X_1, X_0$ to the ROM in figure are 8-4-2-1 BCD numbers, then the outputs $Y_3, Y_2, Y_1, Y_0$ are

(A) gray code numbers
(B) 2-4-2-1 BCD numbers
(C) excess-3 code numbers
(D) none of the above.
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Analyze the circuit diagram: An input BCD digit $X_3 X_2 X_1 X_0$ (weights 8-4-2-1) is decoded into decimal lines 0 to 9 via a BCD-to-Decimal decoder.
  2. The decoder outputs drive the word lines of a diode/ROM matrix that encodes output bits $Y_3, Y_2, Y_1, Y_0$.
  3. Evaluate the ROM mapping for decimal inputs 0 through 9:
  4. • Decimal 0 to 4: Output is identical to binary/BCD ($0000$ to $0100$).
  5. • Decimal 5: Encoded as $1011_2$ (Weight $2+0+2+1 = 5$).
  6. • Decimal 6: Encoded as $1100_2$ (Weight $2+4+0+0 = 6$).
  7. • Decimal 7: Encoded as $1101_2$ (Weight $2+4+0+1 = 7$).
  8. • Decimal 8: Encoded as $1110_2$ (Weight $2+4+2+0 = 8$).
  9. • Decimal 9: Encoded as $1111_2$ (Weight $2+4+2+1 = 9$).
  10. Notice that the code is self-complementing and uses bit weights $2, 4, 2, 1$ (the Aiken code).
  11. Therefore, the ROM implements conversion from standard 8-4-2-1 BCD to 2-4-2-1 BCD code.
Official ExamGOAL Answer Key: (B) 2-4-2-1 BCD numbers
⚠️ Examiner Trap Alert

Excess-3 code for decimal 0 would be 0011, but here decimal 0 produces 0000. Hence it cannot be Excess-3. It is 2-4-2-1 self-complementary BCD.
