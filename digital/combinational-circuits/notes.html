Chapter 06 · Part 1

Adders, Subtractors & Ripple-Carry Propagation Delays

Combinational logic circuits possess no memory elements: their outputs at any instant of time depend strictly on the present combination of input values. In GATE ECE/EE, problems emphasize arithmetic propagation delays, multiplexer functional mapping, and decoder interfacing.

Full Adder & Full Subtractor Core Formulations

Module Primary Output Carry / Borrow Output Minimal 2-input NAND Gates
Half Adder $\text{Sum } S = A \oplus B$ $\text{Carry } C = AB$ 5
Full Adder $S = A \oplus B \oplus C_{in}$ $C_{out} = AB + C_{in}(A \oplus B)$ 9
Half Subtractor $\text{Diff } D = A \oplus B$ $\text{Borrow } B_{out} = \overline{A}B$ 5
Full Subtractor $D = A \oplus B \oplus B_{in}$ $B_{out} = \overline{A}B + B_{in}(\overline{A \oplus B})$ 9

Ripple Carry Adder (RCA) Timing Latency

An $n$-bit Ripple Carry Adder cascades $n$ full adders where the carry output of stage $i$ ripples into the carry input of stage $i+1$:

$$t_{delay} = (n - 1) t_{carry} + \max(t_{carry}, t_{sum})$$

Where $t_{carry}$ is the carry propagation delay per full adder, and $t_{sum}$ is the sum propagation delay.

🎯 Calculation: 16-Bit Ripple Carry Adder Delay (GATE 2014 Set 4, Q31)

Given: $n = 16$ full adders, $t_{carry} = 12\text{ ns}$, $t_{sum} = 15\text{ ns}$.

$$t_{worst-case} = (16 - 1) \times t_{carry} + t_{sum} = 15 \times 12\text{ ns} + 15\text{ ns} = 180\text{ ns} + 15\text{ ns} = 195\text{ ns}$$

The carry ripples through 15 preceding stages before the final 16th full adder computes its sum bit.

Chapter 06 · Part 2

Carry Lookahead Adders (CLA): Generate & Propagate Mechanics

The Carry Lookahead Adder (CLA) eliminates the carry ripple bottleneck by computing all carry signals simultaneously in parallel using two-level logic.

Generate & Propagate Terms

For each bit position $i$:

  • Carry Generate ($G_i$): $G_i = A_i B_i$ (A carry is generated regardless of incoming carry).
  • Carry Propagate ($P_i$): $P_i = A_i \oplus B_i$ (An incoming carry is propagated to the output).

Recursive Carry Expansion

$$C_1 = G_0 + P_0 C_0$$ $$C_2 = G_1 + P_1 C_1 = G_1 + P_1 G_0 + P_1 P_0 C_0$$ $$C_3 = G_2 + P_2 G_1 + P_2 P_1 G_0 + P_2 P_1 P_0 C_0$$ $$C_4 = G_3 + P_3 G_2 + P_3 P_2 G_1 + P_3 P_2 P_1 G_0 + P_3 P_2 P_1 P_0 C_0$$

Every carry bit depends exclusively on primary inputs $A, B$ and initial carry $C_0$. Thus, all carries are available after exactly 2 gate delays (AND-OR levels), regardless of word width $n$!

Chapter 06 · Part 3

Multiplexers as Universal Logic Modules & Tree Cascades

A Multiplexer (MUX) is a digital selector with $2^n$ data inputs, $n$ select lines, and 1 output. Because of its flexibility, it is known as a Universal Logic Module (ULM).

Rules for Realizing Functions Using MUX

  • Using a $2^n:1$ MUX: Any $n$-variable Boolean function can be realized directly by connecting the $n$ variables to the select lines, and tying the data inputs to either '0' or '1' matching the truth table outputs.
  • Using a $2^{n-1}:1$ MUX (Without Inverters): Any $n$-variable Boolean function can be realized using a MUX with only $n-1$ select lines!

    Procedure: Connect $n-1$ variables to select inputs. For each select code, evaluate the output as a function of the remaining $n$-th variable ($Z$). The data input will be $0, 1, Z,$ or $\overline{Z}$.

💡 Cascading Multiplexers Tree Formula (GATE 2004, Q38)

To construct an $M:1$ MUX using smaller $K:1$ multiplexers:

$$\text{Total } K:1 \text{ MUXes} = \frac{M - 1}{K - 1}$$

For example, to build a $4:1$ MUX using $2:1$ MUXes ($K=2$):
$$\text{Total 2:1 MUXes} = \frac{4 - 1}{2 - 1} = 3 \text{ MUXes}$$
To build a $16:1$ MUX using $4:1$ MUXes ($K=4$):
$$\text{Total 4:1 MUXes} = \frac{16 - 1}{4 - 1} = \frac{15}{3} = 5 \text{ MUXes}$$

Chapter 06 · Part 4

Decoders, Demultiplexers & Active-Low Synthesis

A decoder is a combinational circuit that converts an $n$-bit binary code into $2^n$ unique output lines. An active-HIGH decoder generates all canonical minterms ($m_i$); an active-LOW decoder generates all canonical maxterms ($M_i$).

Function Synthesis with Decoders

  • An $n$-to-$2^n$ decoder with an external OR gate can implement any arbitrary $n$-variable Boolean function (connect minterms to OR).
  • An active-LOW $n$-to-$2^n$ decoder (like 74138) with an external NAND gate implements any Boolean function directly due to De Morgan's Law: $$\overline{\overline{m_a} \cdot \overline{m_b} \cdot \overline{m_c}} = m_a + m_b + m_c$$
Chapter 06 · Part 5

Priority Encoders, Magnitude Comparators & Code Converters

Priority Encoders

A Priority Encoder resolves simultaneous input activations by asserting the binary code of the highest-priority active input. In addition, it provides a Valid bit ($V$) that is '1' if at least one input is asserted, and '0' if all inputs are inactive.

Magnitude Comparators

For two $n$-bit binary numbers $A = A_{n-1} \dots A_0$ and $B = B_{n-1} \dots B_0$:

  • Total possible input pairs $= 2^n \times 2^n = 2^{2n}$.
  • Equal combinations ($A = B$): Exactly $2^n$ pairs.
  • Greater-than combinations ($A > B$): By symmetry, $$N_{A > B} = \frac{2^{2n} - 2^n}{2}$$
  • For a 2-bit comparator ($n = 2$ bits): Total pairs $= 16$. Equal pairs $= 4$. $$N_{A > B} = \frac{16 - 4}{2} = 6 \text{ combinations (GATE 2012, Q10)!}$$

Q10. GATE ECE 2012 1 Mark MCQ

The output $Y$ of a 2-bit comparator is logic 1 whenever the 2-bit input $A$ is greater than the 2-bit input $B$. The number of combinations for which the output is logic 1, is

(A) 4
(B) 6
(C) 8
(D) 10
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Inputs $A$ and $B$ are 2-bit numbers ($A, B \in \{0, 1, 2, 3\}$).
  2. Total combinations $= 4 \times 4 = 16$.
  3. Combinations where $A = B$: $(0,0), (1,1), (2,2), (3,3) = 4$ cases.
  4. Remaining combinations where $A \ne B$: $16 - 4 = 12$ cases.
  5. By symmetry, exactly half have $A > B$ and half have $A < B$:
  6. $$N_{A > B} = \frac{12}{2} = 6$$
  7. Listing them: $(1,0), (2,0), (2,1), (3,0), (3,1), (3,2)$.
Official ExamGOAL Answer Key: (B) 6
⚠️ Examiner Trap Alert

Combinatorial symmetry: $\frac{2^{2n} - 2^n}{2} = \frac{16 - 4}{2} = 6$.

Q31. GATE ECE 2014 Set 4 2 Marks NAT

A 16-bit ripple carry adder is realized using 16 identical full adders (FA) as shown in the figure. The carry-propagation delay of each FA is $12\text{ ns}$ and the sum-propagation delay of each FA is $15\text{ ns}$. The worst-case delay (in ns) of the adder is ________.

🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. For an $n$-bit Ripple Carry Adder:
  2. • Stage 0 computes carry in $t_{carry} = 12\text{ ns}$.
  3. • This carry ripples through stages 1, 2, ..., $n-2$.
  4. • Total carry delay through the first $n-1 = 15$ stages is:
    $$t = 15 \times t_{carry} = 15 \times 12\text{ ns} = 180\text{ ns}$$
  5. • In the final 16th stage (FA 15), once the carry arrives at $t = 180\text{ ns}$, the sum bit $S_{15}$ requires an additional $t_{sum} = 15\text{ ns}$ to settle:
    $$t_{worst-case} = 180\text{ ns} + 15\text{ ns} = 195\text{ ns}$$.
Official ExamGOAL Answer Key: 195 (accepted range: 194.9 to 195.1)
⚠️ Examiner Trap Alert

Do NOT compute $16 \times 15 = 240$! The carry ripples through 15 stages ($15 \times 12 = 180\text{ ns}$) and only the last stage waits for sum ($+15\text{ ns}$).
