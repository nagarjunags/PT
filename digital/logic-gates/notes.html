Chapter 05 · Part 1

Basic & Universal Logic Gates (NAND/NOR Synthesis Matrix)

Logic gates are the elementary physical building blocks of all digital computing machines. A gate is defined as universal if any arbitrary Boolean function (and by extension, any digital system) can be synthesized exclusively using that single gate type without requiring external inverters.

Master Table: Minimal Universal Gate Implementations

Memorizing this minimal gate count table is essential for solving GATE speed problems:

Target Function Boolean Expression Min 2-input NAND Gates Min 2-input NOR Gates
NOT (Inverter) $\overline{A}$ 1 1
AND $AB$ 2 3
OR $A + B$ 3 2
NAND $\overline{AB}$ 1 4
NOR $\overline{A + B}$ 4 1
XOR $A \oplus B$ 4 5
XNOR $A \odot B$ 5 4
💡 The 4-NAND XOR Implementation

The classic 4-NAND gate realization of $A \oplus B$:

  1. Gate 1: $G_1 = \overline{AB}$
  2. Gate 2: $G_2 = \overline{A \cdot G_1} = \overline{A \cdot \overline{AB}} = \overline{A} + AB = \overline{A} + B$
  3. Gate 3: $G_3 = \overline{B \cdot G_1} = \overline{B \cdot \overline{AB}} = \overline{B} + AB = A + \overline{B}$
  4. Gate 4: $Y = \overline{G_2 \cdot G_3} = \overline{(\overline{A} + B)(A + \overline{B})} = A\overline{B} + \overline{A}B = A \oplus B$

This exact 4-gate topological structure is tested repeatedly (GATE 2016 Set 3, Q5).

Chapter 05 · Part 2

XOR & XNOR Properties, Parity & Cascaded Invariance

Exclusive-OR (XOR) and Exclusive-NOR (XNOR) gates are arithmetic and parity champions possessing unique algebraic symmetries.

Controlled Inverter Property

  • $A \oplus 0 = A$ (Controlled Buffer)
  • $A \oplus 1 = \overline{A}$ (Controlled Inverter)
  • $A \oplus A = 0$ (Self-annihilation)
  • $A \oplus \overline{A} = 1$
🎯 Cascaded XOR Invariance Theorem (GATE 2002, Q13)

Consider a cascade of $N$ identical XOR gates where one primary input is $X$ and the remaining inputs are tied to logic '1':

$$Y = X \oplus 1 \oplus 1 \oplus \dots \oplus 1 \quad (k \text{ ones})$$
  • If the number of 1s ($k$) is EVEN: Each pair $1 \oplus 1 = 0$, so $Y = X \oplus 0 = X$ (Uncomplemented!).
  • If the number of 1s ($k$) is ODD: $Y = X \oplus 1 = \overline{X}$ (Complemented!).

In GATE 2002 Q13, a cascade of 20 XOR gates with alternating inputs is evaluated instantly using this parity rule.

Chapter 05 · Part 3

Majority Logic Gates & Self-Dual Symmetry

A 3-input majority gate produces a logic '1' if and only if two or more of its inputs are at logic '1'.

Mathematical Formulation

$$M(A, B, C) = AB + BC + CA$$

Factoring out variables reveals alternative structural realizations:

$$M(A, B, C) = AB + C(A + B) = AB + C(A \oplus B)$$
📐 Self-Duality of the Majority Function

The majority function is strictly self-dual:

$$\overline{M(\overline{A}, \overline{B}, \overline{C})} = \overline{\overline{A}\,\overline{B} + \overline{B}\,\overline{C} + \overline{C}\,\overline{A}} = (A + B)(B + C)(C + A) = AB + BC + CA = M(A, B, C)$$

This property is frequently leveraged in fault-tolerant triple modular redundancy (TMR) systems (GATE 2025 Q2, GATE 2015 Q30).

Chapter 05 · Part 4

Propagation Delays, Critical Paths & Static Hazards

Real-world semiconductor gates do not switch instantaneously. Propagation delays through divergent signal paths create transient spurious pulses known as hazards or glitches.

Static Hazards & Their Elimination

  • Static-1 Hazard: The output is expected to remain stable at '1' during an input transition, but momentarily dips to '0' due to path delay skew.

    Cause: Two adjacent minterms in a K-map are covered by separate prime implicants without an overlapping group.

    Remedy: Include the redundant consensus prime implicant in the SOP expression to bridge the transition seamlessly!

  • Static-0 Hazard: The output is expected to remain stable at '0', but momentarily glitches to '1'. (Remedied in POS form by adding consensus sums).
⚠️ Glitch Pulse Width Calculation (GATE 2015 Set 1 Q31, GATE 2002 Q34)

If an input $V_{in}$ splits into two paths to feed a 2-input gate (Path 1 with delay $t_{d1}$, Path 2 with delay $t_{d2}$ where $t_{d2} > t_{d1}$):

$$\text{Glitch Pulse Width } (\Delta t) = t_{d2} - t_{d1}$$

The glitch persists exactly for the duration during which the two competing paths hold conflicting logic values.

Chapter 05 · Part 5

Ring Oscillators ($f = 1/(2Nt_{pd})$) & Sub-Nanosecond Measurement

A ring oscillator is constructed by connecting an odd number ($N$) of inverting stages in a closed feedback loop ($N \ge 3$). Because an odd number of inversions has no stable DC operating point, the circuit oscillates continuously.

First-Principles Derivation of Ring Oscillator Frequency

Let each inverter have propagation delay $t_{pd}$:

  1. Suppose the output of inverter 1 transitions from LOW to HIGH at time $t = 0$.
  2. This transition propagates through all $N$ inverters in cascade, taking time: $$t_{half} = N \times t_{pd}$$
  3. When this signal reaches the input of inverter 1 at time $t_{half}$, it forces inverter 1 to transition from HIGH to LOW.
  4. This second transition must again propagate through all $N$ inverters to return the circuit to its initial state, taking another $N \times t_{pd}$.
  5. Therefore, one complete oscillation period comprises two round trips: $$T = 2 \times t_{half} = 2 N t_{pd}$$
  6. The fundamental oscillation frequency is: $$f = \frac{1}{T} = \frac{1}{2 N t_{pd}}$$
🔬 Measuring Sub-Nanosecond Gate Delays in Silicon

Ring oscillators are universally fabricated on test chips to measure transistor switching speeds because measuring sub-nanosecond $t_{pd}$ directly with an oscilloscope probe is distorted by probe capacitance. Instead, engineers measure the low-frequency output $f$ on a frequency counter and compute:

$$t_{pd} = \frac{1}{2 N f}$$

Q14. GATE ECE 2001 1 Mark MCQ

For the ring oscillator shown in the figure, the propagation delay of each inverter is $100\text{ ps}$. What is the fundamental frequency of the oscillator output?

(A) $10\text{ GHz}$
(B) $5\text{ GHz}$
(C) $1.67\text{ GHz}$
(D) $3.33\text{ GHz}$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Count the number of inverting stages in the ring oscillator: $N = 3$ stages.
  2. Given: Propagation delay per inverter $t_{pd} = 100\text{ ps} = 100 \times 10^{-12}\text{ s}$.
  3. Oscillation period formula:
    $$T = 2 N t_{pd} = 2 \times 3 \times 100\text{ ps} = 600\text{ ps} = 600 \times 10^{-12}\text{ s}$$
  4. Fundamental frequency:
    $$f = \frac{1}{T} = \frac{1}{600 \times 10^{-12}\text{ s}} = \frac{10^{12}}{600} = 1.667 \times 10^9\text{ Hz} = 1.67\text{ GHz}$$
  5. Matches Option (C).
Official ExamGOAL Answer Key: (C) 1.67 GHz
⚠️ Examiner Trap Alert

Do NOT forget the factor of 2 in $T = 2 N t_{pd}$! The pulse must make TWO traversals to complete a full cycle.

Glitch duration is the difference in arrival times between the fast path and slow path.
