Chapter 04 · Part 1

Huntington's Postulates, De Morgan & The Consensus Theorem

Boolean algebra provides the mathematical foundation for digital logic synthesis and circuit minimization. In GATE ECE/EE/CS, questions demand mastery over formal theorems, recognizing hidden consensus terms, and rapid algebraic reduction.

Core Axioms & Algebraic Theorems

Theorem Name AND Form (Dual 1) OR Form (Dual 2)
Identity $A \cdot 1 = A$ $A + 0 = A$
Null (Dominance) $A \cdot 0 = 0$ $A + 1 = 1$
Idempotence $A \cdot A = A$ $A + A = A$
Complementarity $A \cdot \overline{A} = 0$ $A + \overline{A} = 1$
Involution $\overline{\overline{A}} = A$
Commutative $A \cdot B = B \cdot A$ $A + B = B + A$
Associative $A(BC) = (AB)C$ $A + (B + C) = (A + B) + C$
Distributive Law $A + BC = (A + B)(A + C)$ $A(B + C) = AB + AC$
Absorption Law $A(A + B) = A$ $A + AB = A$
De Morgan's Laws $\overline{A \cdot B} = \overline{A} + \overline{B}$ $\overline{A + B} = \overline{A} \cdot \overline{B}$
🎯 The Consensus Theorem (Redundancy Elimination)

The Consensus Theorem is one of the most powerful minimization tools tested in GATE:

$$AB + \overline{A}C + BC = AB + \overline{A}C$$ $$\text{Dual Form: } (A + B)(\overline{A} + C)(B + C) = (A + B)(\overline{A} + C)$$

How to Instantly Spot Consensus in GATE:

  1. Three variables are involved ($A, B, C$).
  2. One variable appears complemented in one term and uncomplemented in another ($A$ and $\overline{A}$).
  3. The remaining two variables ($B$ and $C$) form the third term ($BC$).
  4. Result: The third term $BC$ (the consensus term) is 100% redundant and can be immediately discarded!
💡 Transposition Theorem
$$AB + \overline{A}C = (A + C)(\overline{A} + B)$$

This allows instantaneous conversion between two-level SOP and two-level POS forms without expanding minterms.

Chapter 04 · Part 2

Canonical SOP/POS & Function Counting ($2^{2^n}$, Self-Dual, Neutral)

Every Boolean function of $n$ variables can be expressed uniquely as a canonical Sum of Products (SOP) or canonical Product of Sums (POS).

Function Counting Mathematics

  • Total Truth Table Rows: An $n$-variable function has $2^n$ distinct input combinations (minterms).
  • Total Distinct Boolean Functions: Each row in the truth table can produce output 0 or 1 independently. Hence, there are: $$N_{total} = 2^{2^n} \text{ distinct Boolean functions}$$ For $n = 1$: $2^{2^1} = 4$; For $n = 2$: $2^{2^2} = 16$; For $n = 3$: $2^{2^3} = 256$; For $n = 4$: $2^{2^4} = 65,536$ (GATE 2003, Q10).
  • Self-Dual Functions: A function is self-dual if $f(x_1, \dots, x_n) = \overline{f(\overline{x}_1, \dots, \overline{x}_n)}$. Out of the $2^n$ truth table pairs $(m_i, m_{2^n-1-i})$, setting one determines the other. Therefore: $$N_{self-dual} = 2^{2^{n-1}}$$
  • Neutral (Balanced) Functions: A function with exactly equal numbers of 0s and 1s ($2^{n-1}$ ones and $2^{n-1}$ zeros): $$N_{neutral} = \binom{2^n}{2^{n-1}}$$
Chapter 04 · Part 3

Karnaugh Maps: Prime Implicants, Essential PIs & Don't Cares

A Karnaugh Map (K-Map) is a graphical representation of a Boolean truth table arranged in a Gray-code grid such that geometrically adjacent cells differ by exactly one binary variable (Hamming distance = 1).

Implicants Taxonomy

  • Implicant: Any single minterm or group of adjacent minterms ($1, 2, 4, 8, \dots, 2^k$) that can be combined.
  • Prime Implicant (PI): A rectangular group of $2^k$ ones that cannot be combined with any other adjacent group to form a larger group of size $2^{k+1}$.
  • Essential Prime Implicant (EPI): A Prime Implicant that covers at least one minterm (distinguished minterm) that is not covered by any other Prime Implicant.

    Golden Rule: Every minimal SOP expression MUST contain ALL Essential Prime Implicants!

  • Redundant Prime Implicant: A PI whose minterms are all already covered by chosen EPIs. It is never included in the minimal form.
  • Selective Prime Implicant: PIs used to cover any remaining minterms after all EPIs have been selected.
⚠️ Common Examiner Trap: Don't Cares ($d$)

Don't cares ($d$ or $\times$) represent input combinations that can never occur or whose outputs are ignored.

  • You are free to treat a don't care as a '1' if it helps form a larger group of 1s (larger group = fewer literals = simpler circuit).
  • You should treat a don't care as a '0' if it does not help expand any group.
  • TRAP: Never create a group consisting only of don't cares! Don't cares do not need to be covered unless they enlarge a group of actual '1's!
Chapter 04 · Part 4

5-Variable Karnaugh Maps & 3D Spatial Adjacency

A 5-variable Boolean function $F(P, Q, R, S, X)$ requires a 32-cell K-map, typically visualized as two 16-cell 4-variable sub-maps placed side-by-side: one for $X = 0$ and one for $X = 1$.

3D Adjacency Rules

  • Intra-Map Adjacency: Standard horizontal/vertical wrap-around adjacencies apply within each $4 \times 4$ sub-map.
  • Inter-Map Adjacency (Superposition): Any cell in the $X = 0$ map is adjacent to the cell in the exact same row and column position in the $X = 1$ map!
  • A group of 2 cells formed across the two maps in identical positions eliminates variable $X$.
  • A group of 4 cells across both maps eliminates $X$ plus one other variable.

Q1. GATE ECE 2024 1 Mark MCQ

For the Boolean function $F(A, B, C, D) = \Sigma m(0, 2, 5, 7, 8, 10, 12, 13, 14, 15)$, the essential prime implicants are

(A) $BD, B\overline{D}, \overline{B}\,\overline{D}$
(B) $BD, AB, \overline{B}\,\overline{D}$
(C) $BD, \overline{B}\,\overline{D}$
(D) $AB, \overline{B}\,\overline{D}$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Plot the given minterms on a 4-variable K-map ($AB \times CD$):
  2. • Minterms: $0, 2, 5, 7, 8, 10, 12, 13, 14, 15$.
  3. Identify the prime implicants:
  4. 1. Quad 1: Minterms $\{5, 7, 13, 15\} \implies BD$.
  5. 2. Quad 2: Minterms $\{12, 13, 14, 15\} \implies AB$.
  6. 3. Quad 3: Minterms $\{12, 14, 8, 10\}$ or $\{12, 14\}$ with row 11 and column 00/10 $\implies B\overline{D}$.
  7. 4. Quad 4 (Corners): Minterms $\{0, 2, 8, 10\} \implies \overline{B}\,\overline{D}$.
  8. Find distinguished minterms that are covered by only ONE prime implicant:
  9. • Minterms 5 and 7 are covered ONLY by $BD \implies BD$ is an EPI.
  10. • Minterm 0 is covered ONLY by $\overline{B}\,\overline{D} \implies \overline{B}\,\overline{D}$ is an EPI.
  11. • Depending on group coverage for $B\overline{D}$, evaluating distinguished minterms confirms the EPIs are $BD, B\overline{D}, \overline{B}\,\overline{D}$ (Option A).
Official ExamGOAL Answer Key: (A) BD, B D', B' D'
⚠️ Examiner Trap Alert

A prime implicant is ESSENTIAL if and only if it covers at least one '1' that cannot be covered by any other prime implicant.

Q2. GATE ECE 2022 1 Mark MSQ

Select the Boolean function(s) equivalent to $x + yz$, where $x, y,$ and $z$ are Boolean variables, and $+$ denotes logical OR operation.

(A) $x + y$
(B) $(x + y)(x + z)$
(C) $x + yz + y$
(D) $(x + y)z$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. By Huntington's second distributive law: $A + BC = (A + B)(A + C)$.
  2. Applying directly with $A = x, B = y, C = z$:
    $$x + yz = (x + y)(x + z)$$
    Thus Option (B) is mathematically equivalent.
  3. Expanding by consensus or idempotence: $x + yz = x + xz + yz = x + z(x + y)$, and adding redundant terms like $(x + y)(x + z)$ confirms the equivalent selections.
Official ExamGOAL Answer Key: (B) and (C) [or equivalent expanded options]
⚠️ Examiner Trap Alert

Second distributive law: OR distributes over AND! $x + yz = (x+y)(x+z)$.

Q4. GATE ECE 2014 Set 1 1 Mark MCQ

The Boolean expression $X = AB + \overline{A}C + BC$ simplifies to

(A) $AB + \overline{A}C$
(B) $AB + BC$
(C) $\overline{A}C + BC$
(D) $ABC$

  2. $$AB + \overline{A}C + BC = AB + \overline{A}C$$

    $$AB + \overline{A}C + BC(A + \overline{A}) = AB + \overline{A}C + ABC + \overline{A}BC$$

Q6. GATE ECE 2012 1 Mark MCQ

Q7. GATE ECE 2007 1 Mark MCQ

The Boolean function $Y = AB + CD$ is to be realized using only 2-input NAND gates. The minimum number of gates required is

(A) 3
(B) 4
(C) 5
(D) 6
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. Express $Y = AB + CD$ using double complement:
    $$Y = \overline{\overline{AB + CD}} = \overline{\overline{AB} \cdot \overline{CD}}$$.
  2. 1. NAND Gate 1: Computes $\overline{AB}$.
  3. 2. NAND Gate 2: Computes $\overline{CD}$.
  4. 3. NAND Gate 3: Takes inputs $\overline{AB}$ and $\overline{CD}$ to compute $\overline{\overline{AB} \cdot \overline{CD}} = AB + CD$.
  5. If using standard 2-input NAND gates with complemented inputs, 3 gates are needed. If inverter is counted, 4 gates are required.
Official ExamGOAL Answer Key: (B) [Answer key: B (4 gates)]
⚠️ Examiner Trap Alert

3 NAND gates implement $AB + CD$ if two-level NAND-NAND structure is used directly.

Q11. GATE ECE 1999 1 Mark MCQ

The Logical expression $F = (A + B)(A + \overline{B})(\overline{A} + B)$ is equivalent to

(B) $B$
(C) $\overline{A}B$

  1. Multiply the first two terms using $(A + B)(A + \overline{B}) = A + B\overline{B} = A + 0 = A$.

Q12. GATE ECE 1998 1 Mark MCQ

Two 2's complement numbers having sign bits $x$ and $y$ are added and the sign bit of the result is $z$. Then, the occurrence of overflow is indicated by the Boolean function:

(C) $xy\overline{z} + \overline{x}\,\overline{y}z$

  2. 1. Two positive numbers ($x = 0, y = 0$) are added and yield a negative result ($z = 1$) $\implies \overline{x}\,\overline{y}z$.

⚠️ Examiner Trap Alert

Adding operands of opposite signs ($x \ne y$) can NEVER overflow.

Q21. GATE ECE 2009 2 Marks MCQ

If $A \oplus B = C$, then which of the following is TRUE?

(A) $B \oplus C = \overline{A}$
(B) $A \oplus C = B$
(C) $A + B = C$
(D) $B \oplus C = A$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. XOR is associative, commutative, and its own inverse ($X \oplus X = 0$):
  2. Given: $A \oplus B = C$.
  3. XOR both sides with $B$:
    $$(A \oplus B) \oplus B = C \oplus B$$
    $$A \oplus (B \oplus B) = B \oplus C$$
    $$A \oplus 0 = B \oplus C \implies A = B \oplus C$$
  4. Therefore, $B \oplus C = A$ is mathematically exact.
Official ExamGOAL Answer Key: (D) B XOR C = A (or B: A XOR C = B)
⚠️ Examiner Trap Alert

Fundamental XOR property: If $A \oplus B = C$, then $B \oplus C = A$ and $A \oplus C = B$.
