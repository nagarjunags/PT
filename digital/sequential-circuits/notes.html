Bistable Elements & Asynchronous Latches

Sequential circuits possess internal memory: their present output depends not only on the present primary inputs, but also on the past sequence of inputs (the internal stored state). The fundamental elementary memory element is the cross-coupled bistable multivibrator (latch).

Cross-Coupled NOR vs NAND Latches

A latch uses regenerative positive feedback between two inverting gates to lock into one of two stable operating states: logic '1' (Set) or logic '0' (Reset).

Characteristic Active-HIGH NOR Latch Active-LOW NAND Latch ($\overline{S}\text{-}\overline{R}$)
Schematic Topology Two cross-coupled 2-input NOR gates Two cross-coupled 2-input NAND gates
Active Control Level Active HIGH (assert with '1') Active LOW (assert with '0')
Memory / Hold State $S = 0, R = 0 \implies Q_{next} = Q, \overline{Q}_{next} = \overline{Q}$ $\overline{S} = 1, \overline{R} = 1 \implies Q_{next} = Q, \overline{Q}_{next} = \overline{Q}$
Set Condition $S = 1, R = 0 \implies Q = 1, \overline{Q} = 0$ $\overline{S} = 0, \overline{R} = 1 \implies Q = 1, \overline{Q} = 0$
Reset Condition $S = 0, R = 1 \implies Q = 0, \overline{Q} = 1$ $\overline{S} = 1, \overline{R} = 0 \implies Q = 0, \overline{Q} = 1$

⚠️ Examiner Trap: Metastability on Forbidden State Exit (GATE 2017 Q7)

If an active-LOW NAND latch has inputs $\overline{S} = \overline{R} = 0$ (forcing $Q = \overline{Q} = 1$), and the inputs simultaneously transition to the hold condition $\overline{S} = \overline{R} = 1$:

  • Both gates attempt to transition their outputs from $1 \to 0$ simultaneously.
  • Because the gates possess non-zero and physically unequal propagation delays ($t_{pd1} \ne t_{pd2}$), the gate with the smaller propagation delay switches to $0$ first.
  • This zero feeds back to the other gate, locking it at $1$.
  • Conclusion: The circuit arbitrarily settles into either $(Q=1, \overline{Q}=0)$ or $(Q=0, \overline{Q}=1)$. If delays were mathematically identical, the circuit would linger indefinitely at an intermediate voltage $V_{DD}/2$ in an unstable equilibrium known as metastability.

Transparent D-Latch Timing & Duty Cycle Modulation

A transparent D-latch is level-sensitive: when the enable/clock input $CK$ is HIGH, the output tracks the data input directly ($Q = D$). When $CK$ falls LOW, the latch freezes and stores the last data value present before the falling edge.

📌 Latch Output Waveform under Delayed Clock Inputs (GATE 2017 Q6)

When a D-latch is driven by two clocks where $CK = CLK1$ (50% duty cycle, period $T$) and $D = CLK2$ (delayed by $T/5 = 0.2T$ with 50% duty cycle):

  • $CLK1 = 1$ over the time window $[0, 0.5T]$. The latch is transparent.
  • $CLK2$ is $0$ over $[0, 0.2T]$, and rises to $1$ at $t = 0.2T$, remaining $1$ until $0.7T$.
  • During the transparent window $[0, 0.5T]$, $Q$ follows $CLK2$: it stays $0$ from $0$ to $0.2T$, and switches to $1$ at $0.2T$.
  • At $t = 0.5T$, $CLK1$ falls to $0$. The latch enters latching mode and retains $Q = 1$.
  • At $t = T$, $CLK1$ rises to $1$ again. At this instant, $CLK2$ is $0$ (since $CLK2$ was $1$ from $0.2T$ to $0.7T$, and $0$ from $0.7T$ to $1.2T$). Thus, $Q$ drops to $0$ at $t = T$.
  • High Duration of $Q$: $Q = 1$ from $t = 0.2T$ to $t = 0.5T$ (duration $= 0.3T$).
  • Output Duty Cycle: $\frac{0.3T}{T} \times 100\% = 30\%$.

Clocked Flip-Flops & Master-Slave Physics

A flip-flop is an edge-triggered bistable storage element that samples its data inputs strictly at an infinitesimal transition instant (rising or falling clock edge) and ignores input changes during the rest of the clock cycle.

Master-Slave Architecture & Elimination of Race-Around

In a level-triggered JK latch with $J = K = 1$, whenever the clock pulse is HIGH, the output continuously toggles. If the clock pulse width $t_p$ is greater than the gate propagation delay $t_{pd}$:

$$t_p > t_{pd} \implies \text{Continuous uncontrolled toggling during } CLK = 1 \text{ (Race-Around Condition)!}$$

The Master-Slave Solution:

  • Two cascaded latches: a Master and a Slave driven by complementary clock signals ($CLK$ and $\overline{CLK}$).
  • When $CLK = 1$: Master latch is enabled and responds to inputs $J, K$, while Slave latch is disabled ($\overline{CLK} = 0$), holding the primary circuit output $Q$ completely stable.
  • When $CLK$ transitions $1 \to 0$: Master latch is isolated from inputs, and Slave latch is enabled ($\overline{CLK} = 1$), copying the Master's state to the primary output.
  • Because at no instant are both latches simultaneously transparent, race-around is 100% eliminated!

Flip-Flop Conversion Methodology

To convert an available flip-flop (e.g., JK) into a target flip-flop (e.g., D or T):

  1. Construct a combined truth table with Present State $Q$, Target Inputs, Next State $Q_{next}$, and the required Available Inputs.
  2. Look up the excitation values of the available flip-flop for each transition $Q \to Q_{next}$.
  3. Use Karnaugh Maps to express each available input as a minimal Boolean function of the target inputs and present state $Q$.
Section 3

Setup, Hold & Dynamic Timing Closure

Reliable sequential digital operation requires strict adherence to physical dynamic timing windows around the clock edge.

Fundamental Dynamic Timing Definitions

  • Setup Time ($t_{su}$): Minimum duration for which data input $D$ must remain stable prior to the active clock transition.
  • Hold Time ($t_h$): Minimum duration for which data input $D$ must remain stable after the active clock transition.
  • Clock-to-Q Delay ($t_{cq}$): Time elapsed between the active clock transition and the resulting valid transition of output $Q$.
  • Clock Skew ($\delta = t_{clk2} - t_{clk1}$): Difference in arrival times of the active clock edge at two different flip-flops. Positive skew means the receiving flip-flop receives the clock later than the transmitting flip-flop.
🎯 The Two Master Timing Constraints of VLSI Digital Design

For any register-to-register data path with maximum combinational logic delay $t_{comb,max}$ and minimum combinational logic delay $t_{comb,min}$:

$$\text{1. Setup Time Constraint (Limits Maximum Operating Frequency):}$$ $$T_{clk} + \delta \ge t_{cq} + t_{comb,max} + t_{su}$$ $$T_{clk,min} = t_{cq} + t_{comb,max} + t_{su} - \delta \implies f_{max} = \frac{1}{T_{clk,min}}$$

Setup slack: $T_{clk} + \delta - (t_{cq} + t_{comb,max} + t_{su}) \ge 0$.

$$\text{2. Hold Time Constraint (Prevents Race-Through Data Corruption):}$$ $$t_{cq} + t_{comb,min} \ge t_h + \delta \implies t_{comb,min} \ge t_h + \delta - t_{cq}$$

Hold slack: $(t_{cq} + t_{comb,min}) - (t_h + \delta) \ge 0$.

⚠️ CRITICAL GATE INSIGHT: Hold Time is Independent of Clock Period!

Notice that the clock period $T_{clk}$ does NOT appear in the hold time inequality! A hold time violation cannot be fixed by reducing the clock frequency! In physical chip design, hold violations can only be resolved by inserting delay buffers into the fast data path ($t_{comb,min} \uparrow$) or adjusting clock skew!

Shift Registers, Ring & Johnson Counters

A shift register is a cascade of flip-flops sharing a common clock net where data bits are shifted synchronously from one stage to the next on each clock edge.

Ring Counters vs Johnson (Twisted Ring) Counters

Parameter Ring Counter Johnson (Twisted Ring) Counter
Feedback Connection Direct output $Q_N \to D_1$ Inverted output $\overline{Q}_N \to D_1$
Number of Flip-Flops ($N$) $N$ flip-flops $N$ flip-flops
Modulus (Distinct Valid States) $\text{MOD } N$ ($N$ valid states) $\text{MOD } 2N$ ($2N$ valid states)
Unused States $2^N - N$ unused states $2^N - 2N$ unused states
State Encoding One-Hot (e.g. $1000 \to 0100 \to 0010 \to 0001$) Walking Ring (e.g. $0000 \to 1000 \to 1100 \to 1110 \to 1111 \dots$)
Decoding Logic Zero gates needed (outputs are directly one-hot) Requires one 2-input AND gate per state
Glitch-Free Decoding Inherently glitch-free Glitch-free (adjacent states differ by only 1 bit!)

Linear Feedback Shift Registers (LFSR) & PRBS

An LFSR uses feedback XOR gates from specific tap positions to generate pseudo-random binary sequences (PRBS). For an $n$-stage LFSR with a primitive feedback polynomial, the maximum length of the output sequence is:

$$\text{Maximal Sequence Length } (L_{max}) = 2^n - 1 \text{ clock cycles}$$

The all-zeros state ($00\dots0$) is an illegal absorbing state that must be excluded, since $0 \oplus 0 = 0$ leaves the register permanently trapped.

Section 5

Asynchronous (Ripple) & Synchronous Counters

Asynchronous (Ripple) Counters

In a ripple counter, only the first flip-flop receives the external input clock. Each subsequent flip-flop is clocked by the output of its preceding stage. Flip-flops operate in toggle mode ($T=1$ or $J=K=1$).

📌 Up/Down Asynchronous Counting Rules
Clock Trigger Polarity Clock Derived From Counter Mode
Negative Edge Triggered ($\downarrow$) Normal output $Q$ UP Counter ($0, 1, 2, \dots$)
Negative Edge Triggered ($\downarrow$) Inverted output $\overline{Q}$ DOWN Counter
Positive Edge Triggered ($\uparrow$) Normal output $Q$ DOWN Counter
Positive Edge Triggered ($\uparrow$) Inverted output $\overline{Q}$ UP Counter ($0, 1, 2, \dots$)

Ripple Delay Bottleneck: The cumulative propagation delay limits the maximum operating clock frequency:

$$T_{clk} \ge N \times t_{pd} \implies f_{max} = \frac{1}{N \times t_{pd}}$$

Truncated Counters (Feedback Clear)

To design a MOD-$N$ asynchronous counter using an $n$-bit counter ($2^{n-1} < N \le 2^n$), a NAND gate detects the binary code of state $N$ and drives the active-LOW asynchronous clear ($\overline{CLR}$) pins of the flip-flops. State $N$ is only momentary (a transient glitch of duration $\approx t_{clear}$), after which the counter immediately resets to $0$.

Synchronous Counters

All flip-flops receive the exact same clock pulse simultaneously, eliminating cumulative ripple delay. Operating frequency is bounded only by a single flip-flop clock-to-Q delay plus combinational feedback logic delay.

Section 6

Finite State Machines (Mealy vs Moore Models)

A Finite State Machine (FSM) is a formal sequential model consisting of a finite set of states, inputs, outputs, and state transitions triggered by clock edges.

Mealy vs Moore Machines Comparison

Parameter Mealy Machine Moore Machine
Output Dependency Depends on Present State AND Primary Inputs: $Y = g(S, X)$ Depends ONLY on Present State: $Y = g(S)$
Output Synchronization Asynchronous: changes immediately when input $X$ changes Synchronous: changes only on clock edges
Number of States Typically fewer states (by 1 state for sequence detectors) Typically requires 1 additional state
Glitch Susceptibility Prone to glitches from input noise Glitch-free, robust
💡 The Sequence Detector Golden Rule for GATE

When designing an FSM to detect an $m$-bit binary pattern (e.g., "1011" has $m=4$):

  • Moore Machine: Always requires exactly $m + 1$ states (one state for 0 matched bits, plus $m$ states for 1, 2, ..., $m$ matched bits).
  • Mealy Machine: Always requires exactly $m$ states (the detection output is asserted on the transition entering the $m$-th bit).

    $$2^{n-1} < N \le 2^n$$

Q5. GATE ECE 1 Mark NAT / Subjective

Q7. GATE ECE 2017 Set 1 1 Mark MCQ

In the latch circuit shown, the NAND gates have non-zero, but unequal propagation delays. The present input condition is: $P = Q = '0'$. If the input condition is changed simultaneously to $P = Q = '1'$, the outputs $X$ and $Y$ are

(A) $X = '1', Y = '1'$
(B) either $X = '1', Y = '0'$ or $X = '0', Y = '1'$
(C) either $X = '1', Y = '1'$ or $X = '0', Y = '0'$
(D) $X = '0', Y = '0'$
🎯 Complete Step-by-Step Derivation & Concept Mapping
  1. For inputs $P = Q = 0$ in the cross-coupled NAND latch, each NAND output is forced HIGH: $X = \overline{0 \cdot Y} = 1$ and $Y = \overline{0 \cdot X} = 1$.
  2. When inputs transition simultaneously to $P = Q = 1$, both NAND gates receive $1$ on their primary inputs and $1$ from the cross-coupled inputs.
  3. Both gates attempt to transition their outputs from $1 \to 0$.
  4. Because the gates have unequal propagation delays ($t_{pd1} \ne t_{pd2}$):
  5. • If the gate producing $X$ is faster ($t_{pd1} < t_{pd2}$), $X$ switches to $0$ first. This $0$ feeds into the other NAND gate, preventing $Y$ from falling and forcing $Y = 1$. Result: $X=0, Y=1$.
  6. • If the gate producing $Y$ is faster ($t_{pd2} < t_{pd1}$), $Y$ switches to $0$ first, forcing $X = 1$. Result: $X=1, Y=0$.
  7. Therefore, the final settled state is either $X=1, Y=0$ or $X=0, Y=1$ (Option B).
Official ExamGOAL Answer Key: (B)
⚠️ Examiner Trap Alert

This is a classic metastability resolution problem: physical delay mismatch breaks symmetry and forces the latch into one of its two stable complementary states.
