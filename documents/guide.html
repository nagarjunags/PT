Quick Guide: Standalone HTML Hierarchy

You can organize any number of folders and HTML files inside this project directory.

How it works: The main index.html explorer reads your folders, automatically builds a hierarchical navigation tree, and previews each file inside an interactive viewer.

Adding New Files

  • Create any subfolder, e.g. prototypes/mobile/ or experiments/v1/
  • Place any standalone HTML file inside it
  • Click Select Folder in the navigation bar, drag the folder in, or run python3 scan.py to update the catalog!
